Your Tube Timer setup guide

Tube Timer is a Mac app. This site explains setup; your Gumroad receipt provides purchased files and access.

Get your download

After a completed purchase, open the download link in your Gumroad receipt or library. Download the Mac DMG. If you downloaded a delivery ZIP, unzip it first to find the DMG and instructions.

Open the Tube Timer Gumroad listing and use “Already bought this?” if you need your receipt link. Purchase availability is controlled by Gumroad.

Install on your Mac

  1. Use macOS 13 Ventura or newer.
  2. Open the DMG and drag Tube Timer to Applications.
  3. Open Tube Timer. This early release is not notarized by Apple. If macOS blocks the first launch, use System Settings → Privacy & Security → Open Anyway, only after confirming you downloaded the expected file.
  4. Create your parent PIN and review the daily, session, break and entertainment limits.
  5. Open YouTube in a supported browser and allow Tube Timer’s browser Automation request.

Supported desktop browsers: Chrome, Safari, Brave, Edge and Arc. For precise playback detection in Chrome, enable View → Developer → Allow JavaScript from Apple Events.

Know the limits

This version covers supported browsers on this Mac. It does not cover mobile YouTube, television, Windows or Firefox. Overall viewing limits also apply to learning videos. Video classification can make mistakes; review your rules and channel allowances.

Settings are stored locally. Public video information is read from YouTube. Enabling the optional Claude AI filter sends video information to Anthropic using your API key.

A determined person with administrator access can quit or remove software. Tube Timer is not a guarantee of bypass prevention or a health outcome.

Need help?

Use the seller contact option on your Gumroad receipt. Include the app version, macOS version, browser and what happened. Leave children’s names and other private details out.
